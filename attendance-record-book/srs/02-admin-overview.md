# SRS: 관리자 대시보드 (Admin Overview)

## 개요
관리자 페이지의 전체 구조 및 탭 구성

---

## P1: 관리자 대시보드 구조

### 접근 제어
- [x] 관리자(`role: "admin"`) 전용 페이지
- [x] `/admin` 하위 모든 페이지 권한 검사 (AdminRouteGuard)
- [x] 세션 안전장치: 관리자 영역(`/admin`) 벗어나면 자동 로그아웃 (AdminSessionWatcher)
- [x] 외부 기기에서 로그인 가능

### 통합 탭 구조
- [x] 3개 주요 탭으로 구성:
  1. **지점 및 직원 관리** (`admin-branch-employee.md` 참고)
  2. **근무 시간 관리** (`admin-attendance-management.md` 참고)
  3. **재고 관리** (`admin-inventory.md` 참고)

### 레이아웃
```
┌─────────────────────────────────────────┐
│  관리자 대시보드                          │
│  로그아웃 | 지점 정보                    │
├─────────────────────────────────────────┤
│ [지점 및 직원] [근무 시간] [재고]       │
├─────────────────────────────────────────┤
│                                         │
│       (각 탭별 콘텐츠)                  │
│                                         │
└─────────────────────────────────────────┘
```

## P1: 로그인 및 세션 관리

### 관리자 로그인
- [x] Firebase Auth 기반 로그인 (`/admin/login`)
- [x] Email/Password 또는 Google 로그인
- [x] 로그인 후 `role: "admin"` 확인

### 세션 관리
- [x] 세션 자동 로그아웃: `/admin` 영역 벗어나면 로그아웃 처리
- [x] 로컬스토리지에서 지점 ID 유지

---

## P3: 향후 개선

### 스케줄 관리
- [ ] 스케줄 등록 (사장님이 직원별 근무 예정 시간 등록)
- [ ] 스케줄 확인 (오늘 누가 출근 예정인지 확인)

## 기술 구성

### 컴포넌트
- `AdminRouteGuard`: `/admin` 접근 권한 검사
- `AdminSessionWatcher`: 세션 자동 로그아웃
- 탭 UI: Tailwind CSS 기반

### 라우팅
```
/admin/
  ├── login/           (로그인)
  ├── page.tsx         (탭 구조 메인)
  ├── branch-employee/ (지점 및 직원)
  ├── attendance-logs/ (근무 시간)
  └── inventory/       (재고 관리, 추후)
```
