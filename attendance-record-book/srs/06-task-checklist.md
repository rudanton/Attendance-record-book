# 태스크 체크리스트 기능 명세서

## 1. 개요

### 1.1 목적
직원들이 일일 업무(청소, 재고 점검 등)를 체계적으로 관리하고 누가 수행했는지 기록할 수 있는 체크리스트 기능을 제공합니다.

### 1.2 사용자
- **직원**: 태스크를 수행하고 자신의 이름을 입력하여 기록

### 1.3 주요 기능
- 태스크 목록을 날짜별로 표시 (행: 태스크, 열: 날짜)
- 태스크 추가/삭제 기능
- 각 셀을 클릭하여 직원 이름 입력
- 완료한 직원 정보 및 시간 자동 기록
- 월간 단위 조회

## 3. 기능 설명

### 3.1 메인 화면 기능

#### 기능
- **태스크 검색**:
  - 상단 검색창에 입력하면 태스크 행 필터링
  - 한글 초성 검색 지원 (예: "ㅊㅅ" → "청소")
  - [지우기] 버튼으로 검색 초기화
- **빈 셀 클릭**: 
  - 직원 선택 모달 표시 (검색 가능한 목록)
  - 직원 이름 클릭 시 즉시 체크 표시
  - 검색창에서 실시간 필터링
- **체크된 셀 클릭**: 
  - 삭제 확인 모달 표시
  - [삭제] 클릭 시 기록 제거 (체크 해제)
  - [취소] 시 아무 동작 없음
- **마우스 호버**:
  - 체크 위로 마우스를 올리면 툴팁으로 수행자 이름 표시
  - 예: "홍길동"
- **날짜 표시**:
  - 오늘 날짜 열은 배경색 강조
  - 과거/미래 날짜 모두 입력 가능
  - 한 달(1일~31일) 전체 표시
- **태스크 관리**:
  - [+ 태스크 추가] 버튼으로 새 태스크 추가
  - 각 태스크 행의 [×] 버튼으로 삭제
  - 태스크 삭제 시 관련 완료 기록도 모두 삭제
- **모바일**: 좌우 스크롤 가능

## 3. 데이터 구조

### 3.1 Firestore 컬렉션: `taskCompletions`

태스크 수행 기록
```typescript
interface TaskCompletion {
  id: string;                    // 문서 ID
  branchId: string;              // 지점 ID
  taskName: string;              // 태스크 이름 (예: "청소", "재고 점검")
  date: string;                  // 날짜 (YYYY-MM-DD)
  completedBy: string;           // 수행한 직원 ID
  completedByName: string;       // 수행한 직원 이름
  completedAt: Timestamp;        // 수행 시간
}
```

### 3.2 태스크 목록 정의

처음에는 기본 태스크 목록 제공
```typescript
const DEFAULT_TASKS = [
  "청소",
  "재고 점검", 
  "쓰레기 버리기",
  "온도 체크"
];
```

**태스크 관리 방식 (두 가지 옵션):**

**옵션 1: localStorage 사용 (간단한 데모)**
- 지점별 태스크 목록을 localStorage에 저장
- `taskList_${branchId}` 키로 관리
- 빠른 구현, 브라우저 간 동기화 없음

**옵션 2: Firestore 컬렉션 사용 (프로덕션)**
```typescript
// Firestore 컬렉션: tasks
interface Task {
  id: string;
  branchId: string;
  name: string;
  order: number;        // 표시 순서
  createdAt: Timestamp;
  isActive: boolean;    // 삭제 대신 비활성화
}
```

### 3.3 직원 목록 조회

활성 직원 목록은 기존 `getActiveEmployees()` 함수 사용
```typescript
// 기존 함수 재사용
import { getActiveEmployees } from '@/lib/employeeService';
```

### 3.4 복합 인덱스 (Firestore Index)

```
Collection: taskCompletions
- branchId (Ascending)
- date (Descending)
- taskName (Ascending)
```

| 완료됨 | ✓ (체크)<br/>색상 배경 | 삭제 확인 모달 표시 | 수행자 이름 툴팁 |

### 5.3 검색 기능
- **태스크 검색**: 
  - 상단 검색창에서 태스크 이름 필터링
